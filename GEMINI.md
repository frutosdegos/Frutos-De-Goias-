# Diretrizes do Projeto - Frutos de Goiás

## Regra de Deploy Automático para o GitHub
Sempre que qualquer alteração de código, texto ou layout for realizada neste projeto:
1. Verifique se o Git está instalado e configurado no repositório.
2. Adicione os arquivos alterados com `git add .`.
3. Faça o commit com mensagem explicativa (`git commit -m "..."`).
4. Execute `git push origin main` para enviar imediatamente ao GitHub e disparar o deploy online (GitHub Pages).
5. Se o Git não estiver instalado ou o repositório remoto não estiver configurado, informe ao usuário os passos necessários para habilitar o envio automático.
